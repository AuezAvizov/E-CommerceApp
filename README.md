# 🪖 Military-Shop Android Client

![Platform](https://img.shields.io/badge/Platform-Android-3DDC84?style=flat-square&logo=android&logoColor=white)
![Language](https://img.shields.io/badge/Language-Java-ED8B00?style=flat-square&logo=openjdk&logoColor=white)
![Network](https://img.shields.io/badge/Network-Retrofit2-105191?style=flat-square)

Нативное мобильное приложение-компаньон для интернет-магазина **Military-Shop** (веб-платформа реализована на PHP).

Проект разработан как внутренний инструмент для обеспечения удобного доступа пользователей к экосистеме магазина с мобильных устройств. Приложение демонстрирует навыки построения клиент-серверной архитектуры на Android и работу с REST API.

---

## ✨ Ключевой функционал

* 🔐 **Единая авторизация:** Вход и регистрация пользователей с синхронизацией данных через общую базу веб-версии магазина.
* 🧩 **Модульный интерфейс:** Использование `Fragments` и `Activities` для создания гибкого, масштабируемого и переиспользуемого UI.
* 🌐 **Сетевое взаимодействие:** Интеграция библиотеки **Retrofit** для эффективного и асинхронного обмена данными с сервером.
* 🔄 **Единая экосистема:** Бесшовный пользовательский опыт для управления активностью как на сайте, так и в мобильном приложении.

---

## 🛠 Технологический стек

* **Язык разработки:** Java
* **Платформа:** Android SDK
* **Архитектура UI:** Activities, Fragments
* **Сеть (Network API):** Retrofit 2
